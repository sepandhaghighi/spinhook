## Overview

**SpinHook** is a fast-paced hyper-casual arcade game built with Phaser 3.

Launch from one rotating orbit to another with perfect timing.
Each successful hook increases your score while the game gradually becomes more challenging.

Easy to learn but difficult to master, SpinHook rewards precision, rhythm, and quick decision-making.

🌐 **Live Game:** [https://spinhook.ir](https://spinhook.ir)

## Features

- Endless arcade gameplay
- One-touch controls
- Procedurally generated orbit layouts
- Increasing difficulty
- Mobile and desktop support
- Leaderboard
- Smooth camera movement
- Neon-inspired visuals
- Built with Phaser 3

## How to Play

1. Press **Play**.
2. Your hook rotates around the current orbit.
3. Click or tap to launch.
4. Reach the next rotating orbit.
5. Continue hooking from orbit to orbit.
6. Missing the next orbit ends the game.

## Local Development

To test SpinHook locally, you can use [Ghps](https://github.com/sepandhaghighi/ghps) a minimal GitHub Pages simulator written in pure Python.

Run:

```console
ghps --port 8000
```

Then open your browser and visit:

```console
http://localhost:8000
```
