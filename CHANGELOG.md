# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](http://keepachangelog.com/en/1.0.0/)
and this project adheres to [Semantic Versioning](http://semver.org/spec/v2.0.0.html).

## [Unreleased]
### Added
- Attach sound effect

- `GameScene.generateNextOrbit` method
### Changed
- `README.md` updated
- `GameScene.attachToOrbit` method updated
## [0.2] - 2026-08-05
### Added
- Version label
- Leaderboard
### Changed
- `connectProbe` method renamed to `attachToOrbit`
- `triggerCrash` method renamed to `gameOver`
- `README.md` updated
## [0.1] - 2026-07-24
### Added
- Initial public release of SpinHook
- Core orbit-to-orbit grappling gameplay
- Dynamic orbit generation with progressive difficulty
- Infinite vertical progression with smooth camera tracking
- Particle effects and camera shake for gameplay feedback
- Main menu, HUD, and Game Over screens
- Local high score saving
- Responsive desktop and mobile support
- Touch and mouse controls
- SEO metadata and PWA support
